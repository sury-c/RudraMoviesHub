# RUDRA MOVIES

A mobile-friendly, premium dark-themed movie discovery starter built with Next.js.

## Deploy on Vercel

1. Extract this ZIP.
2. Upload the files and folders inside the extracted `rudra-movies-clean` folder to the **root** of a new GitHub repository. Do not upload the outer folder itself.
3. Import that repository into Vercel.
4. Framework Preset: **Next.js**
5. Root Directory: leave blank / repository root.
6. Output Directory: leave the default setting (do not override it with `public`).
7. Deploy.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
